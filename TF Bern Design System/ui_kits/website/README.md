# Website UI Kit

Click-through mock (Startseite, Lehre, Beruf, Kontakt) built only from the exported components in `components/`.

- Colours: TF Blau (100/80/65/50 %), Schwarz, Weiss. Warm grey #A5ACAE only as image placeholder.
- Spickel on full-width images and blue info boxes only, 25 % of the shorter side.
- Logo top left; white version on the black footer (CD variant 4).
- Content (Berufe, «Was brauchst du für die Lehre?», 3-1-Modell, Karriere, Standorte, slogan) is taken from the examples in the CD manual. Phone numbers and e-mail addresses are left out because the manual's only contact is a named person.
