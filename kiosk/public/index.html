So funktioniert's

  1. 1Du beschreibst dein Bild, auf Deutsch oder einer anderen Sprache.

  4. 4Das Bildmodell malt das Bild Schritt für Schritt aus reinem Rauschen, mit dem Foto als Vorlage.

Profi-Einstellungen

Schritte So oft entfernt das Bildmodell Rauschen. Mehr Schritte geben mehr Feinschliff, dauern aber länger. Probier mal 4 und 30.
16
Seed Die Startzahl für das Rauschen. Gleicher Text und gleicher Seed ergeben dasselbe Bild.
Sampler Der Rechenweg, mit dem das Rauschen Schritt für Schritt entfernt wird.
Prompt-Verbesserer Aus: Dein Text geht direkt ans Bildmodell, ohne Sprachmodell. Schreib dann am besten auf Englisch.
Recherche im Web Bei bestimmten Orten, Bauwerken oder Fahrzeugen schlägt die KI zuerst im Web nach, wie sie aussehen. Dauert ein paar Sekunden länger.
Referenzfoto Die KI schaut ein freies Foto von Wikipedia an, damit das Motiv echt aussieht. Automatisch: bei bestimmten Orten, Bauwerken, Fahrzeugen, seltenen Tieren oder bekannten Personen. Immer: auch bei Alltäglichem und Fantasie-Motiven.
